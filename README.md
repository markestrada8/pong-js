# Pong.js 🎮

A DOM-based implementation of the classic Pong game using vanilla JavaScript, HTML, and CSS. No canvas, no libraries — just pure logic and pixel-chasing fun.

## Features
- Keyboard controls (W/S for left, ↑/↓ for right)
- Real-time ball physics with vertical bounce and paddle collision
- Dynamic score tracking
- Game loop managed with `setInterval`

## Why This Project?
This was a challenge to build a simple yet complete game using only core web tech — no external dependencies, no canvas. It reflects a focus on logic, interaction, and DOM manipulation.

## Possible Improvements
- Add sound effects
- Create a game over / reset screen
- Implement increasing difficulty (faster ball speed)
- Convert to canvas for smoother performance
